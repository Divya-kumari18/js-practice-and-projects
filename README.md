### 💻 Capstone Project — LuxeStock

**LuxeStock** is an inventory management dashboard designed with a modern, elegant interface.

**Key Features**
- 📦 Product inventory management
- ➕ Add and remove products
- 🔍 Search and filter inventory
- 📊 Dashboard statistics and inventory value
- 🏷️ Automatic product categorization by price
- ⚠️ Low-stock monitoring
- 💰 Sales calculator with discount and tax
- 💾 Local storage for saving inventory data
- 📱 Responsive dashboard layout

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layouts
- **JavaScript** — Logic, DOM manipulation, events, and local storage
- **Git & GitHub** — Version control
